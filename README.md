# Recruiter-App-Salesforce-CRM
# 🟢 Recruiter App — Salesforce CRM

A comprehensive end-to-end Recruitment Management System built on Salesforce Lightning Platform.

## 📌 Features
- ✅ Custom objects: Job Postings, Positions, Candidates, Applications & Reviews
- ✅ Interactive Reports & Dashboards with donut & bar chart visualizations
- ✅ Custom tabs, navigation menus & Lightning Experience setup
- ✅ Job application summary reports & position matrix charts
- ✅ Salary analysis using donut and bar chart visualizations
- ✅ Dedicated Recruiter App home page for streamlined workflows

## 🛠️ Tech Stack
- Salesforce Lightning Experience
- Custom Objects & Fields
- Reports & Dashboards
- Salesforce App Builder

## 📂 Custom Objects
| Object | Purpose |
|--------|---------|
| Job Posting | Manage open positions |
| Position | Track job roles |
| Candidate | Store applicant details |
| Job Application | Link candidates to positions |
| Review | Feedback & evaluation |

## 📊 Dashboards & Reports
- Job Application Summary Report
- Position Matrix Chart
- Salary Analysis (Donut & Bar Charts)
